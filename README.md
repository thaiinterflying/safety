# TIF Workplace Safety & Incident Report Form

แบบฟอร์มรายงานอุบัติเหตุและเหตุการณ์ผิดปกติ (Appendix A) — Thai Inter Flying Co., Ltd. (Safety Management Department)

## รายละเอียดไฟล์ในระบบ
* `index.html` — หน้าเว็บแบบฟอร์มรายงานอุบัติเหตุ/เหตุการณ์ผิดปกติ (พร้อมระบบส่งข้อมูล)
* `Google_Apps_Script_Code.js` — โค้ดสำหรับติดตั้งบน Google Sheets เพื่อบันทึกข้อมูลและส่งอีเมลแจ้งเตือนไปยัง Safety & Compliance
* `server.js` — ตัวรันเว็บเซิร์ฟเวอร์แบบเบา (Node.js) สำหรับทดสอบบนเครื่อง
* `start_server.bat` — ดับเบิ้ลคลิกเพื่อรันเซิร์ฟเวอร์และเปิดหน้าเว็บทันที
